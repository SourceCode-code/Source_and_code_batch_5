WHAT IS XPATH ? 
XPATH IS STANDS FOR XML LANAGUAGE


// ABSSOLUTE XPATH VS REALTIVE XPATH 


ABSSOLUTE XPATH :-

1 ABSSOLUTE xPATH WILL ALWAYS START FORM THE ROOT ELEMENT ('HTML')
2 USES THE COMPLETE PATH FORM THE ROOT TO THE TARGET ELEMENT
3 MORE FRAGILE BECAUSE ANY CHANGE IN PAGE STRUCTURE CAN BREAK YOUR XPATH 
4 USUALLY LONGER AND HARDER TO MAINTAIN


REALTIVE XPATH :- 

1 STARTS FORM ANYWHERE IN THE DOCUMENT ('//')
2 USES ATTRIBUTE OR RELATIONSHIPS TO LOCATE THE ELEMENT 
3 MORE ROBUST AND FLEXIBLE 
4 SHORTER AND EASIER TO MAINTAIN


NOTE :- 
WE WILL ALAWYAS PREFER RELAVTIVE XPATH 


HOW TO FIND A ELEMENT USING XPATH 

AT START 

/ -> INDICATES SLEECT FORM ROOT (ABSSOLUTE XPATH)

EXAMPLE 
/html/body/div/div[1]/div/div[1]/div/div[2]/div[2]/form/div[1]/div/div[2]/input

// -> INDICATES SELECT ANYWHERE FORM THE REST  (REALTIVE XPATH)

EXAMPLE :- 
//*[@id="app"]/div[1]/div/div[1]/div/div[2]/div[2]/form/div[1]/div/div[2]/input


IN MIDDLE

/ -> INDICATES SELECT THE DIRECT CHILD 
// -> INDICATE SELECT ANY DECENDANT OF ELEMENT

// GENERAL FORMULA 

//TAGNAME[@ATTRIBUTENAME = "ATTRIBUTEVALUE"]

= --> EQUAL TO
